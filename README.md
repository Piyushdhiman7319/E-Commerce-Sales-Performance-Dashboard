📊 E-Commerce Sales Performance Dashboard | 2024-2025

An interactive E-Commerce Sales Performance Dashboard built in Microsoft Excel to track Sales, Profit, Regional Performance & Category Trends.

📌 Project Overview

This dashboard provides a complete overview of E-Commerce sales for 2024-2025. Built from scratch by cleaning raw data in Power Query and creating an interactive dashboard with Slicers.

📈 Dashboard Highlights

* Total Orders: 1,514
* Total Sales: ₹13.60 Cr
* Total Profit: ₹3.30 Cr
* Interactive Visuals: Sales Trend 2024 vs 2025, Sales by Region, Sales by Category, Profit by Category

Interactive Filters:

* Year (2024, 2025)
* Sales Channel (Online, Offline, Distributor)
* Customer Segment (Retail, Corporate, Institutional, etc.)

🛠️ Tools & Techniques Used

Microsoft Excel | Power Query | Pivot Tables | Pivot Charts | Slicers | Data Cleaning & Transformation | Data Visualization | Dashboard Design

🔄 Data Cleaning Process (Power Query)

* Changed Data Types & Fixed Date Locale
* Trimmed Text & Capitalized Each Word for consistency
* Removed Blank Rows & Errors
* Result: 100% Valid, 0% Errors, 0% Empty — Ready for Analysis

📂 Workbook Structure

1. Sales_Data_Raw - Original raw dataset
2. Cleaned_sales_data - Cleaned & transformed data
3. Pivot_table - Pivot calculations used for analysis
4. Dashboard - Final interactive dashboard

🎯 Key Insights

* South Region is the top-performing region.
* Electronics category drives the highest sales and profit.
* Online Channel contributes a major share of sales.
* Clear seasonality is observed, with peak performance in Oct-Nov 2025.
